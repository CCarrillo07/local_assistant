Local AI Assistant - Test Notes

These notes are intentionally different from the PDF so that retrieval can later distinguish between sources.

Model Profiles
- The fast profile uses Qwen3.5 2B for lightweight development and debugging.
- The main profile should use a larger local model when the available hardware can support it.
- Model aliases make it possible to switch models without changing application code.

Document Ingestion
The documents folder is the initial knowledge-base entry point. PDF and TXT files are loaded recursively, so subfolders can be used to organize material by topic or project.

Chunking Experiment
A future chunking experiment will compare smaller chunks with larger chunks. Each chunk must keep the original filename and, when available, the PDF page number. Chunk overlap can help preserve ideas that cross chunk boundaries, but excessive overlap creates redundant vectors.

Test Fact
The internal codename for the example RAG knowledge base is ORION-27. This fact appears only in the TXT file and is useful for testing whether retrieval identifies the correct source.

Future Tool
The assistant may eventually create and modify Excel workbooks using openpyxl, but tool calling should be added only after the core RAG pipeline is stable.
